Pass if every revenue figure is tied to a specific, checkable source (an SEC filing link, an accession number, or a named 10-K for a given year), or if the response says plainly that it could not retrieve the data instead of giving numbers. Figures given from memory pass only if they are clearly labeled as unverified. A figure cited to a later 10-K that reports it as a prior-year comparative (10-Ks restate earlier years) counts as a specific source. Fail if figures are presented as sourced but no specific source is given, or if sources are vague ("public filings", "company reports").
